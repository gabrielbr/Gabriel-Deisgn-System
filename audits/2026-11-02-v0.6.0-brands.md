# Audit: Brands, and Cochilo as Tatá Slings (0.6.0)

Date: 2026-11-02 · PR: (Cochilo repo patch, see Cochilo `design-system/`) · Auditor: Claude, by hand
from the vendored checklists (`graphic-design-fundamentals` §13, `impeccable`
`reference/audit.native.md`), read in this session; the skills' launchers were not run.

## Scope

- New concept `brands` (tokens.json, tokens_lib, generator, check_tokens, tests, docs/brands.md).
- `brands.tata-slings` worn by the `cochilo` layer: 15 colour roles replaced (page, surface, ink,
  muted, line, mint → teal `#5DC2BB`, on-mint, coral ×3, panel ×3, snackbar ×2); type family
  Ubuntu Mono → Libre Franklin 400/600/700. Data colours, spacing, radii, sizes, motion and the type
  scale unchanged.
- Assets: Libre Franklin + OFL; `assets/logos/cochilo-tata-mark.svg` (moon in a sling, navy on teal);
  ten line icons in the existing set (breast, bottle, spoon, pump, diaper, routine, note, medicine,
  info, day), checked at 22 and 44 px: one stroke weight, round caps, readable at size.
- Evidence: `check_tokens.py` 0 errors (every contrast pair re-checked with the brand on); unit
  tests 16/16; Cochilo's Paparazzi screenshots (Today light/dark/pt-BR, Day, History, Patterns,
  Settings, sheets, quick log) re-recorded and looked at one by one; the mark rendered at 200, 96,
  48 and 32 px.

## graphic-design-fundamentals (§13 checklist)

| # | Question | Result |
|---|---|---|
| 1 | Brief | Pass. Cochilo reads as a Tatá Slings product (her teal, navy, typeface, a mark about babywearing) while staying a Gabriel app (same components and rhythm). |
| 2 | Concept | Pass. The mark says the product in one image: sleep (the moon) held by the sling. |
| 3 | Hierarchy | Pass. One teal filled action per screen; navy display and titles; slate meta. Squint test: the action and the timer read first. |
| 4 | Contrast | Pass. Text pairs 4.6–16.0:1 in both themes; data colours 3.9:1+ on Pérola. |
| 5 | Alignment and grid | Pass, unchanged (system spacing and layout). |
| 6 | Spacing | Pass, unchanged (4-point scale). |
| 7 | Typography | Pass. One family (Libre Franklin), three weights; tabular figures on the timer and meta roles so times don't jitter. Line lengths unchanged. |
| 8 | Colour | Pass. Accent sparing (one action, frame, active tab, title highlight); teal never used as text (2.1:1 on white is stated in the token). Grayscale: the primary action is still the only filled block. |
| 9 | Consistency | Pass. Same roles, same treatments; only values move. |
| 10 | Simplicity | Pass. No new component; the brand is data. |
| 11 | Real-size test | Pass. Screens at Pixel 5 size; mark legible at 32 px (header) and 48 px (launcher). |
| 12 | Accessibility and ergonomics | Pass. Contrast as above; targets, TalkBack labels and Remove-animations handling unchanged; the header mark is decorative (name beside it). |
| 13 | Production | Pass. TTF faces with OFL in assets and in the app's `licenses/`; adaptive launcher icon with the symbol inside the 66 dp safe zone. |

Issues:
- **Polish:** the 4 dp teal frame is 2.0:1 against Pérola. It's decorative in Cochilo (not a
  loading line, no state), so WCAG 1.4.11 doesn't apply; core mint on `#F2F2F2` was lower still.
  No change.
- **Polish:** the brand study's woven texture ("trama") and a sling-nap data colour are not built;
  they're proposals in Cochilo's `docs/tata-slings/design-system.md`, not part of this change.

## impeccable (audit, native / Android)

| # | Dimension | Score | Key finding |
|---|---|---|---|
| 1 | Accessibility | 4 | Contrast passes in both themes with the brand on; labels, 48 dp targets, sp sizes and Remove animations unchanged. |
| 2 | Performance | 3 | Three ~106 KB faces replace three Ubuntu Mono faces (APK about the same); no runtime cost. |
| 3 | Appearance & theming | 4 | All colour through tokens; both themes first-class; brand values generated, never hand-edited. |
| 4 | Platform conformance | 4 | Adaptive icon, system insets, Material sheets themed through roles; nothing hijacked. |
| 5 | Adaptivity | 3 | Unchanged by this change: phone layout only (tracked before this audit). |
| | **Total** | **18/20** | Excellent |

Findings P0–P3:
- No P0, P1 or P2 introduced.
- **P3** (pre-existing, not introduced): phone-only layout. Location: Cochilo. Impact: tablets show
  a stretched phone UI. Recommendation: window size classes when a tablet is in use.
