# Audit: Cochilo "Tecidos" (0.7.0)

Date: 2026-11-02 · PR: patch from the Cochilo repo (`design-system/0002-…`) · Auditor: Claude, from Cochilo's screenshots

## Scope

- `cochilo` layer: data colours `event-night/nap/feed/pump/diaper/daylight` moved to Tatá's
  fabrics; new `event-routine/medicine/note`; `event-*-soft` (9) for the round behind each kind's
  icon; `fab` / `on-fab` (default `{ink}` / `{page}`); `kind-badge` 36px; `radius-s` 4 → 8,
  `radius-m` 8 → 16 (core values).
- `brands.tata-slings`: ink navy `#13293D` → plum-grey `#2B2233`; page `#FBF7F2` → `#FBF5F1`;
  line, muted, panel (plum night), snackbar and dark theme warmed; `fab` Amora `#8A3566` /
  `#E59AC6`, `on-fab` `#FFF7FA` / `#2B1022`.
- Components: Kind icon (new); Log button on `fab`.
- Why: the people logging are mostly mothers; the first look read cold and masculine. Owner chose
  direction A of three (Cochilo `docs/tata-slings/directions.html`).

## graphic-design-fundamentals (§13 checklist)

| # | Question | Result |
|---|---|---|
| 1 | Brief | Warmer and more colourful for mothers, inside every Gabriel rule. ✅ |
| 2 | Concept | "Tecidos": each kind wears one of her fabrics, so the app looks like the slings. ✅ |
| 3 | Hierarchy | Teal stays the one filled action; Amora the second, quieter fill (the Log button); data colours only on icons and timelines. ✅ |
| 4 | Contrast | All pairs pass `check_tokens.py`: ink 14.1:1, on-fab 7.2:1 (dark 8.1:1), fab on page 7.0:1, each `event-*` on its `-soft` 3.9–5.7:1, on page 4.7–7.0:1. ✅ |
| 5 | Alignment and grid | Unchanged; the 36dp round fits the 56dp row and the 52dp Log rows. ✅ |
| 6 | Spacing | Unchanged tokens; Log choices use space-2 padding so four fit beside Feed at 360dp. ✅ |
| 7 | Typography | Unchanged (Libre Franklin). ✅ |
| 8 | Colour | Nine fabric hues told apart by hue family; night (violet) and nap (blue) now differ by hue, not just lightness. Always beside a word. ✅ |
| 9 | Consistency | One component (Kind icon) everywhere an entry kind is shown. ✅ |
| 10 | Simplicity | Line icons kept; colour added by a round, not by redrawing. ✅ |
| 11 | Real-size test | Paparazzi screenshots at phone size, light and dark, English and Portuguese. ✅ |
| 12 | Accessibility and ergonomics | Icons stay decorative beside their word; 48dp targets unchanged. ✅ |
| 13 | Production | Generated `CTokens.kt` copied as is; drift 0. ✅ |

Issues: polish: the Day legend lists the six ring colours only (routine, medicine and note are
not drawn on the ring), which is correct but worth knowing.
