# Audit: brand textures and the Fabric frame (0.8.0)

Date: 2026-11-02 · PR: patch from the Cochilo repo (`design-system/0003-…`) · Auditor: Claude, from Cochilo's screenshots

## Scope

`assets/textures/tata-slings/` (11 crops of her slings), docs/brands.md "Textures", components
Fabric frame and Fabric picker. No token values change.

## graphic-design-fundamentals (§13 checklist)

| # | Question | Result |
|---|---|---|
| 1 | Brief | Let the person pick one of Tatá's real fabrics for the app. ✅ |
| 2 | Concept | The fabric wraps the Today card like a sling wraps the baby; wider on top, like the fold. ✅ |
| 3 | Hierarchy | The card's content is unchanged; the fabric is a frame, the teal action still leads. ✅ |
| 4 | Contrast | No text on any texture. A washed page ground was measured and rejected: 93–96% cover needed for muted text. ✅ |
| 5 | Alignment and grid | Band from spacing tokens (space-8 top, space-3 sides); inner radius-s in outer radius-m. ✅ |
| 6 | Spacing | Card padding unchanged inside the frame. ✅ |
| 7 | Typography | Unchanged; swatch names in meta, one line. ✅ |
| 8 | Colour | Photos carry no meaning; event colours untouched. ✅ |
| 9 | Consistency | One frame component; the picker is the system's selection pattern (ring = selected). ✅ |
| 10 | Simplicity | One setting, one tap, applied at once. ✅ |
| 11 | Real-size test | Paparazzi at phone size: Balão light awake, Tropical dark asleep, picker in Portuguese. ✅ |
| 12 | Accessibility and ergonomics | Swatches are radio buttons with names; 48dp; the frame is decorative. ✅ |
| 13 | Production | 384px WebP, 244 KB for all eleven; mirrored tiling, no seam. ✅ |

Issues: polish: mirrored tiling makes prints symmetric at tile edges (visible on Tropical's
corners); seamless tiles would need retouching each photo.
