# Audit: sleep leads, the Last mark, motion (0.9.0)

Date: 2026-11-02 · PR: patch from the Cochilo repo (`design-system/0004-…`) · Auditor: Claude, from Cochilo's screenshots

## Scope

Size tokens `kind-badge-lead` (44px) and `outline` (2px) in the `cochilo` layer; component Last
mark; Cochilo's motion documented (components.md "Motion"). No colour changes.

## graphic-design-fundamentals (§13 checklist)

| # | Question | Result |
|---|---|---|
| 1 | Brief | Sleep is the main goal: make it lead; make "last" read as a mark, not a word; give every action feedback. ✅ |
| 2 | Concept | One size up for the subject; the kind's own colour says "this one, last time". ✅ |
| 3 | Hierarchy | Sleep rows: bigger round, label role; other kinds unchanged. ✅ |
| 4 | Contrast | The dot and outline use `event-*` (≥ 4.7:1 on page, ≥ 3:1 graphic needed); on a lit option the dot is `on-fab`. ✅ |
| 5 | Alignment and grid | The bigger round keeps the label's start aligned within a list (rows align on their text). ✅ |
| 6 | Spacing | Sleep rows add `space-4` vertical padding instead of `space-3`; timeline rows grow to their words. ✅ |
| 7 | Typography | Existing roles only (label for sleep). ✅ |
| 8 | Colour | Colour never alone: the dot sits before a name, and TalkBack says "used last". ✅ |
| 9 | Consistency | One Last mark in the slide strip, the Log menu, the rows and the sheet. ✅ |
| 10 | Simplicity | A caption removed; nothing added that needs reading. ✅ |
| 11 | Real-size test | Paparazzi: Log menu (light, pt-BR dark), slide strip, History, Day hour by hour. ✅ |
| 12 | Accessibility and ergonomics | Motion snaps with Remove animations; no animation delays an action. ✅ |
| 13 | Production | Two tokens; motion uses the existing two durations only. ✅ |

Issue fixed during the audit: the Day tab's hour-by-hour rows were as tall as their bar, so a
sleep row's bigger round clipped its times; rows now grow to their content.
