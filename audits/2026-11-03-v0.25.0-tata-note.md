# Audit: the Tatá note (0.25.0)

Date: 2026-11-03 · PR: Cochilo 0.32.0 · Auditor: Claude (graphic-design-fundamentals + impeccable)

## Scope

A card for a rare, signed note from the brand's founder with at most one link out. Roles only;
reuses the Quiet link.
