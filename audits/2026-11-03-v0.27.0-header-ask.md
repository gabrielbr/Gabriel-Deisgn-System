# Audit: the header's second icon (0.27.0)

Date: 2026-11-03 · Cochilo 0.38.0

**Why.** Ask Cochilo was reachable only from a row in Patterns, which the owner called "very
hidden". A screen the parent uses from anywhere belongs where Settings already is: the header.

**Rule.** At most two trailing icons, and only when the second opens a screen used from every tab.
Each is a 48dp target; they sit `space1` apart (the IconButton's own padding). The icons come from
the line set (`gg_ic_chat`, `gg_ic_gear`), muted ink, never teal: teal stays the screen's one
action. Each has its own TalkBack label ("Ask Cochilo", "Settings").

**Checks.**
- Hierarchy: the name and the status stay first.
- Spacing: no new values.
- Contrast: the same icon colour as the gear.
- Targets: 48dp.
- 200% font: the status line ellipsizes before the icons move.
